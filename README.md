# TechVision Solutions - Modern IT Company Website

A professional, fully responsive single-page website designed for IT service companies. Built with modern web technologies and best practices.

## ?? Quick Start

1. Open `index.html` in a web browser
2. Or deploy to any static hosting service (GitHub Pages, Netlify, Vercel)

## ?? Features

- ? Fully responsive design (mobile, tablet, desktop)
- ? Smooth scrolling navigation
- ? Animated hero section with counters
- ? Service cards with hover effects
- ? Contact form with validation
- ? SEO optimized with meta tags
- ? Accessibility compliant (WCAG AA)
- ? Fast loading (<50KB total size)
- ? Cross-browser compatible

## ?? Customization

### Update Colors
Edit CSS variables in `assets/style.css`:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #0ea5e9;
}
```

### Update Content
All content is in `index.html` - simply find and replace:
- Company name: "TechVision Solutions"
- Contact information
- Service descriptions
- About section text

## ?? Deployment

### Quick Deploy Options:

**GitHub Pages** (Free)
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin YOUR_REPO_URL
git push -u origin main
# Enable GitHub Pages in repository settings
```

**Netlify** (Free)
- Drag and drop the folder to netlify.com

**Vercel** (Free)
- Import from GitHub or upload files
