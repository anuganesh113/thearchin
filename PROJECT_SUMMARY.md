## 🛠️ Technical Architecture

### Frontend Stack
```
React 18.2          - UI Framework
Tailwind CSS 3.3    - Styling
React Router 6.20   - Navigation
Recharts 2.10       - Data Visualization
Lucide React        - Icons
Vite 5.0            - Build Tool
```

### Component Architecture
```
src/
├── components/       # Reusable UI library
│   ├── common/      # Atomic components
│   └── layout/      # Layout wrappers
├── contexts/        # State management
│   ├── AuthContext  # Authentication
│   └── DataContext  # Application data
├── pages/           # Route components
│   ├── admin/       # Admin features
│   ├── teacher/     # Teacher features
│   ├── student/     # Student features
│   ├── parent/      # Parent features
│   └── shared/      # Shared pages
├── data/            # Mock data
└── App.jsx          # Main app & routing
```

### State Management
- **AuthContext**: User authentication, role checking
- **DataContext**: CRUD operations, data queries
- **localStorage**: Session persistence

### Routing Strategy
- **Public Routes**: Login page
- **Protected Routes**: Role-based access
- **Nested Routes**: Feature organization
- **Redirects**: Unauthorized access handling
